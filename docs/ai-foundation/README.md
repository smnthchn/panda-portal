# AI Foundation Starter Pack

This folder contains the first set of operating documents for your draft-only AI workflow.

Use these files as the source material to copy into Google Docs in your shared Drive.

## Recommended Google Drive structure

1. `01 Brand Voice`
2. `02 Customer Support`
3. `03 Marketing`
4. `04 AI System`

## Starter documents in this folder

- `01-brand-voice-guide.md`
- `02-customer-support-faq.md`
- `03-customer-support-sops.md`
- `04-approved-examples.md`
- `05-ai-prompts.md`

## How to use them

1. Copy each file into its own Google Doc.
2. Replace bracketed placeholders with your real information.
3. Keep the docs short, specific, and current.
4. Treat the final Google Docs as the source of truth for the portal.

## Working rules

- Voice guidance controls style and phrasing.
- FAQ guidance controls factual answers.
- SOP guidance controls process and exceptions.
- Approved examples teach the AI what "good" looks like.
- Prompts should reference the docs above instead of trying to replace them.
